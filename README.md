# AG Neovo Product Gallery

版本：**1.0.8** · [原始碼](https://github.com/jasonwang-tw/AG-Neovo-Product-Gallery)

以 WooCommerce 原生商品圖庫取代本站使用的 Product Gallery Slider，保留主圖、底部縮圖、縮圖箭頭、觸控滑動與燈箱。

## 架構與範圍

- `agneovo-product-gallery.php`：相依檢查、限定預覽、WooCommerce Hook、原生模板選擇及資源載入。
- `assets/gallery.js`：原生縮圖的鍵盤操作、箭頭、水平捲動同步與燈箱雙向滑入／滑出。
- `assets/gallery.css`：專屬作用域的商品主圖、縮圖與原生燈箱樣式。
- 不複製商品／媒體資料；讀取 WooCommerce 現有主圖及圖庫。
- 沿用 WooCommerce 隨附的 FlexSlider 與 PhotoSwipe；沒有第三方 CDN、npm build、額外圖庫引擎或排程。
- 圖庫主圖使用 `large`，縮圖使用 `thumbnail`；桌面 4 張、手機 3 張；不自動播放、不啟用滑鼠懸停縮放。
- WooCommerce 原生模板由目前安裝版本提供，避免在此外掛維護整份模板副本。

## 舊外掛共存與預覽

啟用此外掛時，若 `woo-product-gallery-slider` 仍啟用，一般商品頁繼續使用舊圖庫。停用舊外掛後，新圖庫自動接管單一商品頁。

預覽只影響該次讀取請求，不修改商品或外掛狀態。在 WP-CLI 產生與目標商品 ID 對應的 nonce：

```php
$product_id = /* 已核實的商品 ID */;
$nonce = wp_create_nonce( 'agneovo_product_gallery_preview_' . $product_id );
$url = add_query_arg( 'agneovo_gallery_preview', $nonce, get_permalink( $product_id ) );
```

Nonce 僅供匿名預覽使用，會自然到期；不要把實際值存入公開文件。預覽請求設定 `DONOTCACHEPAGE` 及 no-cache headers，並要求搜尋引擎不要索引。

## 驗證與復原

部署前執行 `php -l agneovo-product-gallery.php` 與 `node --check assets/gallery.js`。
驗證桌面／手機：商品名稱與圖片順序、縮圖切換、前後箭頭、鍵盤操作、原生燈箱開關、觸控滑動、無圖片與單張圖片、加入購物車及結帳頁載入。不得為驗收送出正式訂單。

快取頁面可能仍引用舊外掛資源；切換後須驗證來源新請求與正式網址，只刷新受影響商品頁，不擴大為全站 purge。未完成公開快取驗證時，不可宣稱正式切換完成。

復原：先重新啟用舊外掛，一般頁面即回到舊圖庫，再停用此外掛。兩個外掛與舊設定均保留；商品資料不需要回復。若要回到舊圖庫原本的客製版面，亦須回復本次移除的主題舊圖庫規則；先核對後續修改，不整檔覆蓋其他變更。正式上線後保留新外掛檔案，避免仍在快取中的頁面失去資源。
